Help center

Common questions about CodeLeaf.

These answers explain what the platform is designed to do, how its practice tools behave, and where to find more detail.

What is CodeLeaf?

CodeLeaf is a browser workspace for coding practice, SQL and MongoDB exercises, mentor-created assessments, proctored exams, and coding meetings.

Which languages can I practice?

The workspace includes Python, C, C++, Java, SQL, and MongoDB query workflows. Available execution features can vary by exercise type and room configuration.

Is the SQL tool a hosted MySQL server?

No. It is a bounded educational sandbox that accepts common MySQL-style statements while enforcing limits and isolating the practice state. Use a real MySQL instance to validate production-specific behavior.

Why does a table still exist after I run another cell?

SQL notebook cells share a runtime so that a schema cell can be followed by insert and select cells. Use the runtime reset control when you want to remove the current practice state.

Can mentors create SQL questions?

Yes. Mentors can attach datasets, write an expected SQL answer, preview it with the exam SQL service, freeze the result, and review student submissions.

Should I upload private or production data?

No. Use sample or anonymized data for practice. Never place passwords, tokens, customer records, or other confidential information in a code cell, dataset, exam, or meeting.

How can I report a bug or request help?

Use the Contact page to reach the developer through the project channels. Include the page, steps to reproduce, and a sanitized example; never include credentials.

Is CodeLeaf free?

Core learning features are currently available without a paid subscription. Availability may change as the project evolves; check the relevant page for the current experience.
