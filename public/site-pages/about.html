About the platform

A focused place to practice technical work.

CodeLeaf is a browser-based learning workspace for people who want to write code, work with data, and receive useful feedback without assembling a collection of disconnected tools.

For students

Practice Python, C, C++, Java, SQL, and MongoDB with a code editor, runnable examples, schema inspection, and visible output. Small feedback loops make it easier to understand why a solution works.

For mentors

Create question papers with coding, SQL, query, and multiple-choice questions. Freeze expected results, run a live assessment, review submissions, and use the leaderboard to guide follow-up teaching.

For collaboration

Use a CodeLeaf meeting room to discuss an exercise while keeping the shared editor and workspace nearby. The goal is to make explanation and hands-on work part of the same session.

Why CodeLeaf was built

Programming practice is most effective when a learner can move from an idea to a working experiment quickly. A normal lesson may require an editor, a compiler, a database client, a video call, and a way to collect answers. Switching among those tools adds friction and often hides the reasoning behind the result.

CodeLeaf brings those common learning steps together. It is not intended to replace a production database, a full local development environment, or a formal learning-management system. It is a practice surface: a safe place to try a query, inspect a schema, compare output, and improve the next attempt.

How the main tools work

Code execution

The workspace editor supports common teaching languages and sends bounded execution requests to the server-side compiler path. Output, diagnostics, and run timing stay visible beside the editor so students can iterate without losing context.

SQL and MongoDB practice

The database tools load bounded practice data into an isolated execution environment. SQL exercises support familiar relational operations such as table definitions, keys, joins, grouping, and aggregates. MongoDB exercises use sample collections and query inspection. Read the SQL guide and MongoDB guide for examples.

Assessments

Mentors can create an exam room, attach datasets, define expected answers, and invite students with a room code. Students receive the question text and the relevant editor. SQL and query submissions are executed and compared with the mentor's frozen result.

Built for learning: Keep credentials, secrets, and production data out of practice cells. CodeLeaf is a teaching and experimentation environment; always review a result before using it elsewhere.
