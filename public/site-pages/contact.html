Get in touch

Help us make the learning workspace better.

CodeLeaf is maintained as a practical learning project. Clear bug reports and thoughtful feedback help improve the editor, database playground, assessments, and meetings.

Report a bug

Open an issue in the CodeLeaf GitHub issue tracker. Include the page, browser, steps to reproduce, and a small sanitized example.

Ask a question

Check the FAQ and the About page first. They explain the intended behavior of the main tools and the limits of practice execution.

Connect with the developer

For project discussion and professional contact, reach Prranith Swargam on LinkedIn.

What to include in a useful report

  1. What you were trying to do and which URL or feature you used.
  2. The exact steps that reproduce the behavior.
  3. The expected result and what actually happened.
  4. The browser and device, plus a screenshot or console message when helpful.
  5. A minimal example with secrets, passwords, tokens, personal records, and private datasets removed.

Security note: Never post credentials or private exam data in a public issue. If a report involves sensitive information, describe the behavior without including the data and use the private project contact channel.
