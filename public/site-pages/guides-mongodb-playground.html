Document database learning

Explore documents, then explain the result.

MongoDB practice is easier when you can inspect a collection before writing the query. CodeLeaf gives you sample data, a schema view, a query editor, and a result panel for short, repeatable experiments.

Start with find, projection, and sort

Use a collection available in the database explorer. The exact collection names depend on the selected sample dataset, but the workflow stays the same:

db.products.find({ category: "Books" }, {
  name: 1,
  price: 1,
  _id: 0
}).sort({ price: -1 }).limit(5)

This query filters documents, returns only the fields needed for the exercise, orders the results by price, and limits the output. Run one change at a time so you can tell which part affected the result.

Inspect first

Open the schema or sample document view before guessing field names. Document data can contain nested objects and arrays, so a quick inspection prevents many empty-result queries.

Build pipelines

Use aggregation stages such as $match, $project, $group, and $sort. Keep each stage focused and check the output as your pipeline grows.

Compare results

When a query returns no documents, simplify it: remove the sort, then the projection, then the filter. Rebuild from the first step that returns the expected shape.

A small aggregation exercise

Suppose each product contains category and price. This pipeline groups products by category and calculates a count and average price:

db.products.aggregate([
  { $match: { price: { $gt: 10 } } },
  { $group: {
      _id: "$category",
      items: { $sum: 1 },
      averagePrice: { $avg: "$price" }
  } },
  { $sort: { averagePrice: -1 } }
])

Read the pipeline from top to bottom. First it removes low-priced products, then it groups the remaining documents, and finally it orders the summary.

Practice responsibly

The playground uses bounded sample data for learning. It is not a replacement for validating a query against your own MongoDB version and indexes. Do not upload confidential records or credentials. For relational exercises, switch to the SQL practice guide.
